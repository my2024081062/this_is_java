조인을 여러번 해서 가져오는 방법
1. Entity의 @을 아래와 같이 작성하고
@NamedEntityGraph(name = "RecipeEntity.fetchCookieIngredient"
    , attributeNodes = {
        @NamedAttributeNode(value = "cookie"),
        @NamedAttributeNode(value = "ingredient", subgraph = "RecipeIngredient.fetchCategory")}
    , subgraphs = {
        @NamedSubgraph(name ="RecipeIngredient.fetchCategory", attributeNodes = {
            @NamedAttributeNode(value = "category")})
    }
)
repository에 실행할 crud에 @EntityGraph(value = "RecipeEntity.fetchCookieIngredient")를 붙인다.

2. repository에 실행할 crud에 @EntityGraph(attributePaths = {"cookie", "ingredient", "ingredient.category"})를 붙힌다.
@EntityGraph(attributePaths = {"멤버변수이름1", "멤버변수이름2","외래키멤버변수이름1.외래키멤버변수이름2....) 사용하고있는 멤버변수이름과 정확히 일치해야한다.

트랜잭션, 롤백
@Transaction : 스프링 부트에서 트랜잭션 처리를 위한 어노테이션
이 어노테이션으로 선언된 메소드는 exception이 발생하면 롤백을 시킬 수 있다
롤백을 발생시키면 db에 업로드 되지 않게 할 수 있다.
가능한 예외 : RunTimeException(이 예외에서만 롤백 가능), 
불가능한 예외 : Exception(롤백 불가)
Exception을 롤백하고싶으면 메소드에 @Transactional(rollbackFor = {롤백하고싶은클래스.class}) 어노테이션을 붙인다.
롤백 대상을 catch(예외 e) 안에서 다시 던지지 않으면 롤백이 안되기 때문에 throw e를 해야한다.

서버에 파일을 업로드할때 확장명은 올리지 않는다.
왜냐면 보안이 제대로 지켜지지않을때 파일을 다른 누군가가 볼수도 있다.

mybatis를 쓸 경우 조인되는 아이디와 객체의 아이디 값은 항상 같게 해야한다.

JPARepository는 기본적으로 save(),findById(), deleteById(), findAll()를 지원한다.
JPA에서 조회할때는 select쿼리를 메소드이름으로 만들 수 있다.
findBy~, findAllBy, 이런 이름으로 메소드를 만들면 select쿼리 실행이 가능
findBy멤버변수조회조건정렬조건..();

@어노테이션 : 자바에서 컴파일, 빌드시에 도움을 주는 도구

@Transient // JPA에 테이블을 어떤 컬럼에도 연결시키지 않는다.

@RestController json형식으로 데이터를 주고 받는 컨트롤러 클래스로 만들어준다.

@Autowired : 생성자를 따로 적지 않아도 스프링 부트가 인스턴스로 만들어준다, @Service, @Component 어노테이션이 있는 클래스에만 가능하다.

@Mapping : 
URI => http://주소/aaa/bbb/ccc
Method => 해당매핑
요청데이터 => {"id":값, "name":"값2", ...} (Json)

@JoinColumn 외래키임을 표시, @ManyToOne N:1으로 조인 등.. 조인될 Entity객체 위에 적는다. (JPA)
@ManyToOne(fetch = FetchType.LAZY) 일일이 다 select로 찾아준다.
@ManyToOne(fetch = FetchType.EAGER) 조인을 만들어준다.
내가 직접만든 select문은 EAGER를 써도 조인을 해주지 않는다.
그래서 
@EntityGraph를 써서 조인으로 가져와라 라고 내가 만든 select문 함수 위에 적어주면 조인을 다시 해준다. (attributePaths ="{외래키멤버변수이름}" 씀)

controller : url만들고 웹서버를 만들어 준다.(컨트롤러에 해당하는 주소를 입력하면 처리해준다.)
